# VolleyTakt Live 0.3.1 Preview 2i – r3

Korrekturstand für die Hauptansicht des Scoutings.

- Standard-Feldausrichtung bei neuem regulären oder spontanen Scouting: markierte Symbolhälfte unten.
- Bei deaktiviertem Gegner-Scouting wird der Gegner-Umschalter in der Hauptansicht ausgeblendet.
- Deaktivieren des Gegner-Scoutings setzt den aktiven Scout-Kontext auf das eigene Team zurück.
- Der Feldausrichtungs-Schalter bleibt unabhängig davon sichtbar.
- Einzelfeldansicht detailliert: oben markiert = 1-6-5 / 9-8-7 / 2-3-4 / Netz; unten markiert = Netz / 4-3-2 / 7-8-9 / 5-6-1.
- Einzelfeldansicht einfach: oben markiert = 1-6-5 / 2-3-4 / Netz; unten markiert = Netz / 4-3-2 / 5-6-1.
- Bei Scouting beider Teams bleibt ein gemeinsames Netz mittig.
- Umschaltung verändert keine Positions-, Spieler-, Rotations- oder Rallydaten.

Gezielte Tests: 10/10 Feldorientierung, 8/8 r3 UI, 11/11 finale p2i-Regressionsprüfung.
