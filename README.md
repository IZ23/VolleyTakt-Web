# VolleyTakt Live 0.3.1 Preview 1

Ausgangsbasis: zuletzt korrigierte 0.3.0 Preview 9.

## Neu
- Workflow: WER → WAS → WIE → WO → WOHIN.
- Bei eigenem Aufschlag werden P1 als WER und Aufschlag als WAS vorausgewählt; beide bleiben korrigierbar.
- Detaillierter Aufschlag: Jump Float, Jump Topspin, Float, Standaufschlag, Topspin/Drive, von unten, Sonstige. Englisch: Jump Float, Jump Topspin, Float, Standing Overhand, Topspin/Drive, Underhand, Other.
- Basisbewertung: = / - / 0 / + / #.
- Detaillierte DataVolley-nahe Bewertung: = / - / ! / / / + / #.
- DataVolley-nahe Punktautomatik: = beendet die Rally als Fehler zugunsten der Gegenseite; # beendet nur bei Aufschlag, Angriff und Block automatisch als Punkt der handelnden Mannschaft.
- Sprachabhängige Kurzlegende unter der Bewertung.
- Einheitliches Aktionsdatenmodell für einfaches und detailliertes Scouting; Detailfelder bleiben bei einfacher Erfassung leer.
- Bestehende 9-Zonen-Feldorientierung und Start-/End-Timestamps aus 0.3.0 Preview 9 bleiben erhalten.

- 0.3.1 Preview 1 Korrektur p1d: gemeinsame responsive Scout-UI für einfach und detailliert; Profil unterscheidet nur Inhalt, nicht Touch-Zielgrößen oder Legendenlayout.
