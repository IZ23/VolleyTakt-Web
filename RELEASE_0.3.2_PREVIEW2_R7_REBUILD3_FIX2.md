# VolleyTakt Live 0.3.2 Preview2-r7 rebuild3-fix2

Vollständiger Hotfix auf Basis von Preview2-r7 rebuild3-fix1.

## Korrekturen
- Startseite: Livescouting-Button bleibt auch bei kleinem mobilen Viewport erreichbar.
- Landscape: Viewport/Safe-Area gegen horizontales Überlaufen gehärtet. Ein vom Android-System reservierter Navigationsstreifen liegt außerhalb des Browser-Viewports und kann von einer normalen Webseite nicht belegt werden.
- Felddarstellung: Die markierte obere/untere Scoutseite entspricht nun der tatsächlichen Lage des aktiven Teams; der Aufschlagball wird auf P1 dieser Feldhälfte dargestellt.
- Detailliertes Feld: P1–P9 werden als neun gleich große Zonen in drei gleich hohen Reihen dargestellt.

Lokale Daten werden nicht gelöscht.
