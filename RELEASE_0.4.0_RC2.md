# VolleyTakt Live 0.4.0 RC2

Basis: vollständiger 0.4.0-RC1-Build.

## Änderungen

- **FE-UI10:** Im Spontanscouting werden Feldzellen im kompakten Touch-Landscape vereinfacht. Die Positionsnummer P1–P6 erscheint nur einmal. Das redundante Standard-Quick-Scout-Kürzel P1–P6 wird dort unterdrückt; eigene Trikotnummern/Kürzel bleiben erhalten. Bei geringer Höhe werden sekundäre Namensinformationen reduziert. Positionsarrays, Positionslogik und Desktopdarstellung werden nicht verändert.
- **FE-SCOUT7:** Die bereits in Preview19/RC1 eingeführte monotone Rally-Nummerierung über Undo und einen neuen Zweig bleibt erhalten und wurde für RC2 gehärtet: `rallyHighWater` wird beim Laden normalisiert und nie unter den aktuellen Rally-Zähler gesetzt.

RC2 enthält darüber hinaus keine neue Scoutingfunktion.
