# VolleyTakt Live 0.4.3.3

Patch-Release für die vollständige DE/EN-Lokalisierung des Kamera-Panels.

## Behoben
- `UI-I18N5`: verbliebene deutsche Texte im Kamera-Drawer entfernt.
- Status, Battery/Akku, Quality/Qualität, Connected/Not connected sowie Connect/Disconnect sind sprachabhängig.
- DJI-/GoPro-Anleitung, Qualitäts-Hinweis, Kompatibilitätsinformationen und BLE-Diagnosebeschriftungen sind lokalisiert.

## Kompatibilität
- Datenschema bleibt 6.
- Keine Migration erforderlich.
