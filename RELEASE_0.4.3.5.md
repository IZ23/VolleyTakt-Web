# VolleyTakt Live 0.4.3.5

Patch-Release für die Vorschaltseite / den Schnellstart.

## Behoben
- Der manuelle Schnellstart bleibt auf der Vorschaltseite dauerhaft verfügbar.
- Ein gespeicherter "Nicht mehr zeigen"-Status unterdrückt weiterhin nur den automatischen Rundgang, nicht den manuellen Schnellstart.
- Browser-/Web-Bluetooth-Hinweise verändern die Verfügbarkeit des Schnellstart-Buttons nicht mehr.

## Kompatibilität
- Datenschema bleibt Version 6.
- Keine Migration erforderlich.
- Keine Änderungen an Undo/Redo oder Security-Fixes aus 0.4.3.4.
